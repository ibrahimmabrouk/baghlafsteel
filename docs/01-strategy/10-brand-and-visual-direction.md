# Baghlaf Steel — Brand & Visual Direction

> Strategic definition of the visual identity, aesthetic territory, art direction, interaction character, and design principles for the Baghlaf Steel website.

---

# 1. Purpose

This document defines the strategic visual direction for the Baghlaf Steel website.

It establishes:

- How the website should feel
- What visual territory the brand should occupy
- How the visual system should support trust
- How industrial credibility should be communicated
- How Saudi identity should be represented
- How international B2B professionalism should be expressed
- What visual patterns should be avoided
- How visual direction should translate into the Figma Design System

This document defines visual strategy.

It does not replace the detailed design system in:

`docs/01-strategy/11-figma-design-system.md`

---

5. Brand Personality

The visual personality should be:

Strong

Communicate confidence without aggression.

Precise

Use structure, hierarchy, and disciplined spacing.

Professional

Feel appropriate for serious international B2B procurement.

Transparent

Technical

Use structured information where it improves buyer understanding.

Refined

Use restraint rather than visual excess.

Human

7. Visual Principles
7.1 Structure Over Decoration

Use layout, typography, spacing, imagery, and hierarchy to create visual interest.

Do not depend on decorative elements.

7.2 Contrast With Purpose

Use contrast to establish:

Hierarchy
Focus
Information grouping
CTA prominence

Avoid contrast for purely decorative reasons.

7.3 Whitespace Is a Trust Signal

Generous and intentional spacing should communicate:

Confidence
Organization
Maturity
Clarity

Do not fill every area of the interface simply because space exists.

7.4 Typography Carries Authority

Typography should provide much of the brand's visual character.

The design system should favor:

Strong hierarchy
Intentional weights
Controlled line lengths
Clear technical values
High readability
7.5 Authenticity Over Excess

Real evidence and appropriate imagery should carry more weight than visual effects.

16. Saudi Identity

Saudi identity should be represented authentically and professionally.

It can be communicated through:

Appropriate imagery
Environmental context
Geographic references

Language

Decorative national symbolism

Artificial "Saudi-themed" graphics

17. International B2B Character

The visual experience should feel appropriate for buyers from multiple countries.

It should therefore avoid:

Excessive regional symbolism
Local-only visual conventions
Overly casual language
Consumer-oriented aesthetics

The site should feel internationally legible.

18. Photography Direction

Photography should play an important role in establishing credibility.

Preferred categories:

Industrial Context

Steel, logistics, infrastructure, ports, fabrication, materials.

Supply Context

Shipping, logistics, material handling, yards, transportation.

Human Context

Real professionals, commercial interaction, inspection, coordination.

Saudi Context

Authentic Saudi industrial or logistics environments where relevant.

19. Photography Authenticity

Images must not create a false factual impression.

For example:

A photograph of a manufacturer's factory should not be presented as:

"Baghlaf's factory"

if Baghlaf does not own that facility.

The image context must remain honest.

Overused stock imagery
Images unrelated to the actual business
Images implying unsupported facilities or capabilities

26. Border & Surface Philosophy

Surfaces should communicate structure.

Possible tools:

27. Border Radius

Corner radius should be controlled and consistent.

Extreme pill-shaped containers everywhere
Excessive rounding

More structured shapes should reinforce the industrial character.

Exact values belong in the design system.

28. Shadows

Shadows should provide subtle hierarchy when needed.

Avoid:

Heavy floating shadows
Excessive depth effects
Glassmorphism-style surfaces
Decorative shadows

The interface should rely primarily on composition and contrast.

29. Glassmorphism

Glassmorphism is not a core visual direction.

It should not become a defining characteristic of the website.

If transparency or blur is ever used, it must:

Have a clear functional reason
Remain visually restrained
Support hierarchy
Not resemble a generic AI/SaaS design
30. Gradients

Gradients should not be a defining feature.

They may be used only where they provide a meaningful visual or functional purpose.

Avoid:

Neon gradients

Decorative gradient blobs

Industrial Editorial direction + design system.

Failure 2 — Manufacturer Implication

Symptoms:

Business-model-aware art direction.

Failure 3 — Corporate Template

Symptoms:

Generic hero

Editorial composition + authentic imagery + strong typography.

Failure 4 — Overdesign

Symptoms:

Too much animation
Too many visual effects
Excessive decorative elements

Restraint and purpose-driven interaction.

Failure 5 — Underdesign

Symptoms:

Plain template
Weak typography

Failure 6 — Arabic/RTL Drift

Symptoms:

Broken hierarchy
Mirrored layout without thought
Poor typography
Incorrect icon direction
Mitigation

RTL-first design rules.

71. Final Strategic Principle

Baghlaf Steel should look like a mature, credible Saudi steel trading and supply company built for serious international B2B buyers. The visual identity should use an Industrial Editorial direction grounded in strong typography, structured grids, authentic industrial imagery, technical clarity, restrained color, purposeful motion, and disciplined composition. Modernity should come from quality and thoughtful design rather than fashionable effects. The system must deliberately avoid generic AI/SaaS aesthetics, excessive glassmorphism, decorative gradients, fabricated trust signals, and imagery that could imply Baghlaf owns or operates manufacturing facilities. The visual language should establish confidence through precision, clarity, authenticity, and consistency.


### Why this is the right separation

At this point our strategy layer has a very clean progression:

```text
09-product-and-supply-network
          ↓
"What are we actually representing?"

10-brand-and-visual-direction
          ↓
"How should that reality look and feel?"

11-figma-design-system
          ↓
"What exact design system creates that experience?"

12-ux-wireframes
          ↓
"How does the buyer interact with it?"

There are two particularly important decisions in this file.

First: I made Industrial Editorial the central aesthetic rather than merely saying "premium corporate." That gives Figma and the AI agent a concrete design territory to work within.

Second: the file explicitly protects the project from the two visual failure modes that are most dangerous here:

Generic AI/SaaS design
          +
Visual implication that Baghlaf is a manufacturer

One thing should remain pending management input: the actual logo, existing brand guidelines, official colors, typography, photography, and other corporate assets. If Baghlaf already has an established brand system, that should become the authoritative visual input rather than us inventing a new identity.
